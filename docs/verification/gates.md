# G0–G8 implementation and acceptance matrix

**Version 1.0.0 — audit and repair, 2026-10-09. No gate is declared closed.** Native evidence
below was produced on one macOS 26 / Apple Silicon host with Rust 1.99.0; Python checks,
workflow definitions and installer recipes are not native release evidence for the other
targets. The supplied normative plan's original acceptance criteria remain unchanged. Exact
commands, environment, exit codes and blocked checks: `commands.json` and
`audit-2026-10-09.md` in this directory.
