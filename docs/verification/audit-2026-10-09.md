# Audit and repair register — Huda 1.0.0, 2026-10-09

Scope: architecture-preserving audit of the supplied 2026-10-09 source update, executed on a
native Apple Silicon host (macOS 26.0.1, Darwin 27.0.1, Xcode 27.0, rustup 1.29.1 with the
pinned 1.99.0 toolchain, Python 3.14.8, cargo-audit 0.22.1, shellcheck 0.11.0, system Ruby
for YAML parsing). The handoff had no Git metadata; a SHA-256 baseline of all 169 delivered
files was recorded before any edit. The `README.md`, `CHANGELOG.md`, `docs/`, `AGENTS.md` 
and the previous verification records were used instead.

Classification: **D** confirmed defect · **R** required but incomplete behavior ·
**U** unverified platform behavior · **E** optional enhancement. Severity: S1 data loss,
authorization or egress; S2 build/startup; S3 semantics/lifecycle; S4 robustness/ergonomics.

Rejected hypotheses (not defects after tracing): keyring `default-features=false, features=["v1"]`
does enable the native Keychain, Windows and Secret Service stores (keyring 4.2.0 `Cargo.toml`);
tray-icon `ksni` is a real feature and the only backend enabled on Linux; eframe 0.36.2 exposes
`App::logic`/`App::ui`/`on_exit(Option<&glow::Context>)`; auto-launch 0.6.0 exposes the three
selected launch modes and hard-codes `~/.config/autostart` and unescaped plist strings, so the
Linux quoting and macOS character rejection in `startup.rs` are justified; the IPC deadline,
authentication, cancellation watcher, lease and read-only reader paths behave as documented.

See `commands.json` for the exact commands, exit codes and log files. Summary: `cargo fmt
